# T1.8 — Accessibility quick fixes

`[R]` · size **S** · **Status: not started** · depends on T1.5 for the axe gate

## Why

The design-system audit found the labels are good but the *announcements* are
missing: across 34 feature files there were 50 `aria-*` attributes and 42
`aria-label`s but **zero** `role=`, **zero** `aria-live` and **zero** `sr-only`.
Async status is therefore never announced, and two click targets are `div`/`span`
elements. The sign-in form has three separate defects. These are small, concrete
fixes; the deeper design-system work is T2.13.

## Do

1. **`src/pages/Auth.tsx`:**
   - add `autoComplete="one-time-code"` to the OTP field so the code can be pasted
     and autofilled (WCAG 3.3.8 — the user must not be forced to transcribe);
   - give the error text `role="alert"` (or an `aria-live="assertive"` region) so
     it is announced, and move focus to it;
   - add a resend control with a visible countdown that announces when it becomes
     available.
2. **Replace the two clickable `div`/`span` elements with real `<button>`s** (or
   add the correct role, `tabIndex`, and Enter/Space handling — a real button is
   better and smaller). Find them with a search for `onClick` on non-interactive
   elements.
3. **Live regions for async status.** Identify the long-running operations (AI
   generation, publishing, deploys) and wrap their status text in a
   `role="status"` / `aria-live="polite"` region. Announce start and finish only,
   never every tick.
4. **Skip link** to the main content landmark in the app shell.
5. **Focus visible** on every interactive element you touch; do not remove the
   focus ring.

## Acceptance

- axe reports zero serious violations on `/auth` and `/app`.
- A keyboard-only sign-in works end to end: reach the field, paste the code,
  submit, land in the dashboard, and hear the error announcement.
- No `onClick` remains on a `div` or `span` without a button role and keyboard
  handling.

## Proof to record in the PR

The axe output before and after, and a screen-reader or keyboard transcript of the
sign-in flow.
