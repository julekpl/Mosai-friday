## Do

   this file. That recorded number is the baseline for the ticket.
2. Fix the errors. Categorise them as you go so the PR is reviewable:
   - **Unused variables/imports** — delete them. If a value is genuinely

     and the surrounding component before changing anything.
3. Do not add `eslint-disable` for a whole file, and do not weaken
   `eslint.config.js`.

## What was fixed

### Unused variables / imports (49 → 0)
Deleted the unused imports and dead locals, e.g. `main.tsx` (8 unused lazy route
imports), `ContentEditor.tsx` (unused `Plus` and `dropdown-menu` imports),
`PageRenderer.tsx` (unused `useEffect`/`useState`), `Billing.tsx`
(`StatusBadge`, `user`), `Build.tsx` (`Rocket`, dead `api.builds.update`),
`Overview.tsx` (`MosaicMark`, `Separator`, an unused `CommsDialog` prop and the
unused `removeComms` mutation), `PageEditor.tsx` (two unused queries),
`ads/adapters.ts`, `ads/platforms.ts`, `ads/sync.ts`, `buildChat.ts`,
`shopifySync.ts`, and unused validator params that were destructured but not
read (`ai.ts`, `contentPlanning.ts`, `research.ts`, `social/copilot.ts`) — the
validators were left intact so no client contract changed.

### `any` (22 → 0)
- `src/convex/storefront.ts` (17): dropped the now-redundant `(q: any)` /
  `(p: any)` / `as any[]` / `(revision as any)` annotations; Convex infers the
  index-query and row types from the table name, so the code is now fully typed.
- `src/convex/dal.ts` (5): replaced the `(q: any)` callback params with a local
  `IndexQuery` type (`{ eq(field, value): IndexQuery }`). The documented
  `db = ctx.db as any` handle is unchanged.

### React-hooks errors (11 → 0) — real runtime fixes, not style
- `react-hooks/set-state-in-effect`: `use-mobile.ts` now derives the initial
  value from `matchMedia().matches` (only the change listener writes state);
  `mosaic.tsx` seeds `shown` from `typeof IntersectionObserver`; `StorefrontApp`
  derives the effective variant id instead of syncing it in an effect;
  `BuildWorkspace` drops a redundant effect (the active page already falls back
  to `pages[0]`); `Create.tsx` derives the seed HTML and guards one-time Y.Doc
  hydration with a ref plus a correct dependency array; `carousel.tsx` defers
  the initial embla sync one frame and now also unsubscribes `reInit`.
- `react-hooks/refs` (`PageEditor.tsx`): `dirtyRef` became `dirty` state, so the
  render path no longer reads a ref and autosave reacts to `dirty`.
- `react-hooks/purity`: `sidebar.tsx` no longer calls `Math.random()` during
  render (deterministic width from `useId`); `Create.tsx` passes the research
  timestamp from the click handler instead of calling `Date.now()` in render
  scope.
- `react-hooks/immutability` (`Promote.tsx`): `window.location.href = url`
  became `window.location.assign(url)`.
- Dead `AiVariantsDialog` in `Promote.tsx` is now actually rendered (the "AI
  variants" buttons set `openAi` but nothing consumed it — the dialog was
  dead code, so wiring it up both uses the symbol and restores the feature).

### `react-hooks/exhaustive-deps` warnings (4 → 0)
`Create.tsx` (`topics`), `Journeys.tsx` (`journeys`), `PageEditor.tsx`
(`revisions`) now wrap the query result in `useMemo`; `BuildWorkspace.tsx`'s
warning disappeared with the redundant effect.

## Remaining warnings — deferred, all justified

- **21 × `react-refresh/only-export-components`** — Fast-Refresh ergonomics in
  shared component modules that intentionally co-export small helpers
  (`mosaic.tsx`, `demo-data.tsx`, the shadcn `ui/*` primitives, `main.tsx`,
  `vly-toolbar-readonly.tsx`). Not errors, and splitting these files is out of
  T1.4's scope.
- **4 × unused `eslint-disable` in `src/convex/_generated/*`** — the generated
  file headers emitted by `convex codegen`; the files are machine-owned and must
  not be edited.
