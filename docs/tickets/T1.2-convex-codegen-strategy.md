# T1.2 — Convex codegen strategy

`[R]` · size **S** · **Status: not started** · ⚑ decision required

## Why

`src/convex/_generated` is git-ignored. On a machine that has never run Convex
codegen, every `_generated` import is unresolved and the resulting `implicit any`
cascades make type health impossible to judge — the pack measured **1,067 errors**
on a clean checkout, against **0 errors** once codegen has run (verified:
`bun convex dev --once && bun tsc -b --noEmit` exits 0). Any CI job that
typechecks must therefore generate or restore the folder first.

## Options

| Option | How | Trade-off |
|---|---|---|
| A. Commit `_generated` | Remove it from `.gitignore`, commit it, add a CI drift check (`convex dev --once` then `git diff --exit-code`) | Typecheck works offline and in any CI; the generated code churns in diffs |
| B. Generate in CI | Run codegen against a dedicated CI deployment before typecheck | No committed artifacts; CI needs a deployment plus credentials, and local checkouts still need codegen |

Recommendation: **A with a drift check**, unless the owner objects to committed
generated code. Verify against current Convex guidance before deciding — this
ticket is not a place to guess.

## Do

1. Choose A or B and record the reason in the ticket file.
2. Implement it. For A: remove the `src/convex/_generated` line from `.gitignore`,
   commit the folder, and add the drift check to the CI workflow (the workflow is
   created by T1.5; if T1.5 has not landed, add the check as a script and note it).
3. Make the check part of the project's `check` command so a stale `_generated`
   fails locally too.

## Acceptance

- A fresh clone of the default branch typechecks without any Convex credentials.
- A hand-edit to a `_generated` file fails the drift check.
- No agent or developer is told to hand-edit `src/convex/_generated/*` to fix a
  type error (that is a bug in the source, not the output).

## Proof to record in the PR

Fresh-clone typecheck output, plus the drift check failing on a deliberately
tampered generated file.
