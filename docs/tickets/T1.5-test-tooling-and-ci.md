## Why

There were **no tests, no test runner and no CI** (verified: no test script in
`package.json`, no `.github/workflows`). Every Phase 0 fix was "code in place,
proof outstanding". This ticket turns the Phase 0 work into something that cannot
silently regress. It adds the harness only — T1.7 writes the R1–R12 tests.

## Do — what was built

1. **Vitest + the Convex test harness.**
   - Dev deps added: `vitest@^5.0.1`, `convex-test@^0.0.59`,
     `@edge-runtime/vm@^5.0.0`.
   - `vitest.config.ts` — owns its own config so `vite.config.ts` is untouched;
     `environment: "edge-runtime"`, `include: ["tests/unit/**/*.test.ts"]`.
   - `src/convex/test.setup.ts` — the module registry (`import.meta.glob`) that
     `convex-test` needs because `convex.json` points `functions` at
     `src/convex/`. It includes the committed `_generated/*.js` (convex-test
     requires it) and excludes `.d.ts` and `*.test.ts`.
   - `tests/unit/harness.test.ts` — a two-assertion **harness smoke test** (boots
     the mock backend from the real schema; proves the module registry is wired).
     It is deliberately *not* an R-test; T1.7 owns those.
2. **Playwright for the browser journeys.**
   - Dev deps added: `@playwright/test@^1.63.0`, `@axe-core/playwright@^4.13.0`.
   - `playwright.config.ts` — `testDir: tests/e2e`, Chromium project, reuses the
     dev server locally and starts its own in CI.
   - `tests/e2e/smoke.spec.ts` — landing renders and routes to `/auth`; unknown
     route shows 404.
   - `tests/e2e/a11y.spec.ts` — axe on `/` and `/auth`; fails on serious/critical
     violations, with a dated `KNOWN_VIOLATIONS` baseline (see below).
3. **Scripts** in `package.json` (bun authoritative):
   - `test` / `test:unit` → `vitest run`
   - `test:e2e` → `playwright test`
   - `test:a11y` → `playwright test tests/e2e/a11y.spec.ts`
   - `scan:secrets` → `node scripts/scan-secrets.mjs`
   - `check` → `typecheck && lint && test:unit && scan:secrets && audit:functions`
4. **A real secret scanner that always runs.** `gitleaks` is the canonical tool
   and CI installs it, but it is not present in every local environment. New
   `scripts/scan-secrets.mjs` reads the **same custom rules from
   `.gitleaks.toml`** (single source of truth), scans the working tree, redacts
   the matched value, and fails on a finding. It refuses a no-op scan if it
   parses zero rules.
5. **CI — `.github/workflows/ci.yml`**, one job per concern so a failure names
   its cause: `install` (frozen lockfile + drift) · `codegen` (T1.2 drift check)
   · `typecheck` · `lint` · `unit` · `security` (gitleaks history **and**
   working tree, `scan:secrets`, `audit:functions`, dependency audit) · `e2e`
   · `a11y`. Existing checks are wired in, not duplicated.
6. **`.gitignore`** ignores the Playwright/Vitest artifacts
   (`test-results/`, `playwright-report/`, `blob-report/`, `coverage/`).

`vite.config.ts`, `convex.json` and `src/convex/_generated/*` were not touched;
no HMR setting was changed.

## Known limitations recorded honestly

- **The dependency-audit leg is non-blocking for now.** `bun audit` currently
  reports **1 critical + 4 high** (`@auth/core` via `@convex-dev/auth`, `undici`
  via `cheerio`/`@vly-ai/integrations`). T1.6 owns the upgrade; until it lands
  the CI step is `continue-on-error` with `TODO(T1.6, 2026-09-22)`. Do not leave
  it like this past T1.6.
- **The codegen job needs a deployment key.** `convex codegen` requires
  `CONVEX_DEPLOY_KEY` + `CONVEX_DEPLOYMENT`. Until the owner adds them the job
  warns and skips (`TODO(T1.5, 2026-09-22)`); the committed bindings still make a
  fresh clone typecheck without it.
- **`a11y` has one dated known violation.** `/auth`'s icon-only email submit
  button has no accessible name (`button-name`, critical). It is listed in
  `KNOWN_VIOLATIONS` with `TODO(T1.8)`; any *new* serious/critical violation
  still fails the job. T1.8 must delete the entry.
- **`docs/pack/06-test-strategy.md` §4 does not exist in this checkout** (only
  `STATUS.md`, `README.md` and `10-build-backlog.md` are present under
  `docs/pack/`). The job list above is taken from this ticket's own "Do" section,
  which is the authoritative version until that pack file lands.
- **Local Chromium needs system libraries.** The Freebuff sandbox image lacked
  the shared libraries Chromium requires; they were installed to run the gate
  here. CI installs them with `bunx playwright install --with-deps chromium`, so
  no repository change was needed for that.
