# BP-08/S1 — OAuth state and trusted callback origins

**Status: implemented_unverified (bounded slice).** Developed from GitHub main `274877f` in the existing `bp-03-codex` checkout, then applied with BP-09/S2 and BP-19/mobile navigation to the existing `bp-02-codex` integration checkout. This is not completion of BP-08 or proof of a live provider connection.

Ads and social callbacks now claim OAuth state in one Convex mutation. The claim consumes an expired state, rejects the wrong provider route, and rechecks the initiating user's current access to the bound project before exchanging a code. State generation uses `crypto.randomUUID()`. Callback and app return URLs come from validated configured origins, never the incoming request host. A missing trusted app origin or Convex callback origin makes connection setup unavailable with an actionable explanation; local HTTP is allowed only for localhost development. `.env.example` distinguishes the app return origin from the Convex site callback origin.

Changed paths: `.env.example`, `src/convex/ads/oauth.ts`, `src/convex/social/oauth.ts`, `src/convex/lib/oauthBaseUrl.ts`, `src/convex/lib/capabilities.ts`, `src/pages/app/Promote.tsx`, and `tests/unit/connection-oauth-state.test.ts`.
