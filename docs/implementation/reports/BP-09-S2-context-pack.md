# BP-09/S2 — server-owned AI context and inspector

**Status: implemented_unverified (bounded slice).** Developed from GitHub main `274877f` in the existing `bp-05-codex` checkout, then applied to the existing `bp-02-codex` integration checkout. This does not complete BP-09's grounding, evaluation or external proof.

The affected AI actions now accept authorized project/persona/build/page identifiers rather than client-built persona, journey or build snapshots. `guards.ts` loads the ContextPack from project-owned records, rejects foreign references before model invocation, and bounds source excerpts. Each evidence item carries a source, trust label, deterministic provenance version and reference. The material actually sent to a model is capped at 20 references and 40,000 serialized characters; omitted or shortened evidence is reported as a context gap. Structured persona/journey/product/build/page fields are filtered to complete evidence references that survive the cap, so an omitted record cannot enter the prompt through a second field. User-provided topics, research digests and instructions are labeled unverified request content. Build exposes a collapsible context inspector for the server-loaded context.

Changed paths: `src/convex/ai.ts`, `buildPlan.ts`, `guards.ts`, `sellAI.ts`, `lib/contextPack.ts`, `lib/capabilities.ts`; `src/components/app/ContextInspector.tsx`, `PersonaChat.tsx`; `src/pages/app/Build.tsx`, `Create.tsx`, `Journeys.tsx`, `Overview.tsx`; `tests/unit/context-pack.test.ts`, `phase0-regressions.test.ts`.
